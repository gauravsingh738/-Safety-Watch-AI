# -Safety-Watch-AI
AI-powered personal safety web app with real-time crime risk scoring, live maps, and one-tap SOS alerts via SMS/WhatsApp. Built with Firebase + Leaflet.js.
Safety Watch AI is a browser-based personal safety dashboard that helps users:
Analyze safety levels of any location in real time using AI-driven risk scoring
View nearby police stations and hospitals on an interactive map
Trigger SOS alerts that instantly send their live GPS location to emergency contacts via SMS and WhatsApp
Access emergency helplines (112, 100, 181 Women Safety, 1098 Child) in one tap
✨ Features
